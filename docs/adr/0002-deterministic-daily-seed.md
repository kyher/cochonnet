# Deterministic daily-seeded cochonnet placement

Each end's cochonnet position is generated from a seed derived from the calendar date, rather than placed by the player or randomized per-session. This was chosen over player-thrown or freely-randomized placement because the game's purpose is a comparable, shareable daily score — a random-per-session jack would mean two players' scores reflect different difficulty, not just different skill. The trade-off: jack placement carries no player skill component (unlike real pétanque, where the throwing player places the jack).
